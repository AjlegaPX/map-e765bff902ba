Настройки

Ключ 2ГИС Places API. Без него заведения приходят из OpenStreetMap без рейтингов, и фильтр «не ниже 4» отключён. Демо-ключ выдаётся на dev.2gis.ru после регистрации.

Порог рейтинга

Порог действует только у заведений с известным рейтингом. Заведения без рейтинга показываются серыми, пока не подключён 2ГИС.
